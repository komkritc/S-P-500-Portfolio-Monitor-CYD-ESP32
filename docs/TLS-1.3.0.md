## Known residual risks (accepted, documented)

- No revocation checking (BearSSL has no OCSP/CRL): pinned roots + chain verification is the
  embedded ceiling; same trust level as a browser without OCSP enforcement.
- Leaf `*.www.yahoo.com` expires 2026-12-23; renewal is chain-internal and needs no bundle change.
- If Yahoo ever anchors to a new root, field recovery = one authenticated POST (docs/CERTS.md);
  worst case a USB flash.
- Browser -> device stays plain HTTP (LAN trade-off, unchanged).
